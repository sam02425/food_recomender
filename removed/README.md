# Removed Files - Reference Archive

## Purpose

This directory contains files that were removed from the main repository during the research organization process but are preserved for reference purposes. These files were generated by autonomous systems during the development and testing phases.

## Organization

### `human_experiments_data/`
Contains experiment data files that were generated by autonomous systems but preserved for record-keeping purposes:
- Trial results and summaries
- Comprehensive analysis reports
- Raw experimental data logs

### `system_files/`
Contains autonomous system files preserved for reference:
- Experiment system implementations
- Test and demo scripts
- Analysis tools

### `documentation/`
Contains documentation files that were superseded by the organized documentation structure:
- Various experiment summaries
- Implementation documentation
- Setup and configuration guides

### `logs/`
Contains log files from autonomous experiment runs:
- Timestamped experiment logs
- System operation logs

## Note

These files are preserved for:
1. **Reference purposes** - Understanding the development process
2. **Audit trail** - Maintaining record of autonomous system outputs
3. **Potential future analysis** - Raw data for alternative analysis approaches
4. **Transparency** - Complete record of research artifacts

## Git Ignore Status

The `removed/` directory is tracked in git but the main repository is organized to exclude autonomous system files from active development. This maintains a clean working repository while preserving the complete research record.
