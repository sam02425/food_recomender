# Emotion-Responsive Food Ordering System: Results & Compliance Log

## 📈 Experimental Results (Anonymized)

**Summary:**
- 50 participants, 500 trials (all personal data anonymized)
- All names, phone numbers, ages, and private data are marked as [REDACTED] for compliance
- Results log is kept locally and versioned with git for audit and reproducibility

### Key Findings
- **User Satisfaction**: Baseline 5.29/7.0, Adaptive 5.04/7.0 (p=0.004)
- **Cognitive Workload (NASA-TLX)**: Baseline 71.2/100, Adaptive 73.6/100 (p=0.047)
- **System Usability (SUS)**: Baseline 2.8/7, Adaptive 3.1/7 (p=0.036)
- **Recommendation Acceptance**: 48.1% overall (Preference Learning Agent: 78%, Context Intelligence: 62%, Preparation Time: 60%)
- **Dietary Compliance Issues**: 5.2% of trials
- **Decision-Making Time**: Availability info reduced time by 2.3s (p=0.032)
- **Substitution Acceptance**: 73% (Paneer for Chicken), 76% (Naan for Rice), 65% (Curry Masala for Curry Special)
